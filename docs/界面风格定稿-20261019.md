## 2. 设计 Token（亮 / 暗）

实现载体：`src/index.css` 中 CSS 变量（`:root` 亮色，`.dark` 暗色），tailwind v4 `@theme inline` 映射。
数值与两份预览页完全一致（所见即所得）。

| Token | 亮色 | 暗色 | 用途 |
|-------|------|------|------|
| --background | #FFFFFF | #09090B | 页面底 |
| --foreground | #09090B | #FAFAFA | 正文 |
| --card | #FFFFFF | #111113 | 卡片/表格容器 |
| --popover | #FFFFFF | #101012 | 弹层 |
| --muted | #F4F4F5 | #1B1B1F | 次级填充/hover |
| --muted-foreground | #71717A | #A1A1AA | 次级文字 |
| --border / --input | #E4E4E7 | #27272A | 1px 边框（分层靠边框，不用阴影） |
| --primary | **#18181B** | **#FAFAFA** | 主操作色（近黑，暗色反转） |
| --primary-foreground | #FAFAFA | #18181B | 主按钮文字 |
| --ring | #18181B | #FAFAFA | 聚焦圈 |
| --sidebar | #FAFAFA | #0E0E10 | 侧栏底 |
| --radius | 0.625rem（10px），派生 sm 6 / md 8 / lg 12 | 同左 | 全站圆角一值推导 |
| --up（涨） | #DC2626 | #F87171 | 红涨（A股习惯） |
| --down（跌） | #16A34A | #4ADE80 | 绿跌 |
| --up-bg / --down-bg | rgba(220,38,38,.08) / rgba(22,163,74,.10) | rgba(248,113,113,.12) / rgba(74,222,128,.12) | 涨跌徽标底 |
| --chart-1..5 | #2563EB #0EA5E9 #8B5CF6 #F59E0B #10B981 | #60A5FA #38BDF8 #A78BFA #FBBF24 #34D399 | 图表序列色 |

硬性纪律（跨主题不变）：
1. 数字一律 `font-variant-numeric: tabular-nums`，金额/百分比右对齐。
2. **颜色只承担语义**：红涨绿跌之外，界面不允许出现装饰性彩色（primary 除外）。
3. 分层靠 1px 边框 + 表面色差，不用投影（弹窗/下拉允许阴影）。
4. 数据源与净值截止时间固定展示在侧栏底部；快照/假数据必须显式标注，不静默造假。

## 4. 布局骨架

- 左侧 `AppSidebar`：宽 224px，可折叠为 56px 图标栏（w-14，localStorage 记忆）。
  - 品牌：近黑方块图标（lucide trending-up）+「基金研究工作台」。
  - 分组：**研究**（仪表盘 / 画像库 / 领域探索）、**分析**（组合评估 / 穿透分析）。
  - 底部：数据源与净值截止时间（来自后端，缺省隐藏）。
- 顶部 `SiteHeader`：h-14，面包屑 + 右侧（搜索、主题切换 icon、预留动作）。
- 内容区满宽（max-w-none），路由：/dashboard /library（默认重定向） /library/:code /domain /portfolio /overlap。

## 5. 组件语义

- 徽标：池状态用中性（持仓=描边、研究池=灰底、观察中=虚线描边）；涨跌徽标 = 语义色文字 + 语义色 8-12% 底。
- 表格操作列：ghost 图标按钮（more-horizontal → dropdown）。
- 弹窗：radius 12、细边框、收敛阴影；footer 右对齐（取消 secondary / 确认 primary）。
- 分页：shadcn 风格 ghost 方块，当前页 = muted 底 + 描边（不用实心色块）。
- ECharts 统一：轴文字 muted-foreground 12px、splitLine 1px border 色、tooltip 用 popover token、序列色 --chart-1..5；净值曲线默认 chart-1，收益对比条形用 up/down。

## 7. 迁移步骤

1. 装依赖：tailwindcss v4 + @tailwindcss/vite、shadcn init（zinc / new-york）、lucide-react、@tanstack/react-table、react-hook-form、zod、react-router-dom；`npm rm antd`。
2. `index.css` 重写：双主题 token（§2）+ 密度工具类；删除旧四皮肤全部变量。
3. 搭壳：AppSidebar（可折叠）+ SiteHeader（含主题切换，localStorage key 换新）+ 路由。
4. 重写画像库：TanStack Table + shadcn table + 筛选工具栏 + 入池 Dialog（react-hook-form + zod）+ 行操作 DropdownMenu + KPI 卡。
5. 清理：App.tsx 旧 THEMES/Segmented、assets 模板遗留（hero.png/react.svg）。
6. 验证：`npm run build` 零报错；dev 启动占用 5173（端口保持干净）；亮/暗切换与折叠态刷新后保持。
