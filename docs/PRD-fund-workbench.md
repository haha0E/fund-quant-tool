# PRD · 基金研究工作台 v0.2（需求调研产出物）

> 状态：待用户验收 · 生成于 2026-10-13 · 调研方式：grill-me 十四问逐条澄清
> 修订记录：v0.2（2026-10-13）「候选池」改为「研究池」，新增工具内置领域探索入池机制（FR1/FR4/验收标准同步修订）；v0.1 初稿
> 生命周期：需求调研（本文档）→ 技术选型 → 实现方案 → 实现。每阶段产出物经用户验收后进入下一阶段。

## 1. 背景与定位

用户重仓 5 只场外基金，2026 年 9-10 月组合回撤 14-25%。事后诊断发现名义 5 只、实际 4/5 押注同一 AI 算力行业（新易盛、中际旭创各出现在 4 只基金前十大），而市面工具（招行 App、天天基金）均不提供组合级穿透视角。

**一句话定位：一站式个人基金研究工作台——记录基金画像，自由组合若干基金做综合评估，并穿透到重仓股层面看量化指标。**

与现有资产的关系：本需求是 ROADMAP 阶段 1（fund_metrics.py + 对比报告 + 重叠度实测）的产品化升级，并前移了阶段 3 的重仓股管线一部分。**不另立项目，作为阶段 1 的扩展形态执行。**

## 2. 用户与使用场景

- 单用户（持有人本人），每周研究一次，业余时间每周 6-10 小时。
- 核心用户故事（即 v1 验收场景）：
  1. 录入 5 只持仓 + 7 只候选基金，建「持仓 + 研究池」画像库；
  2. 选中 5 只持仓 → 查看并排指标对比、组合净值/回撤/相关性、基准超额、重叠度穿透；
  3. 穿透表中看到新易盛/中际旭创按组合合计权重排在前列且超标标色；
  4. 点开单基金画像，看到自动数据 + 自己手写的研究结论（买入理由、退出路标）；
  5. 想探索新领域时（如医药），在领域探索页选领域 → 浏览该领域基金列表与初步指标 → 挑选入研究池，打上领域标签。

## 3. 功能需求

### FR1 基金画像库（持仓 + 研究池）
- **范围**：持仓（实盘）+ 研究池（观察对象），总量 10-20 只。池内基金打领域标签（AI/医药/黄金/红利/消费…），画像库页可按领域筛选查看。
- **入池机制（工具内置领域探索，v0.2 新增）**：领域探索页选一个领域 → 自动拉取该领域基金列表 + 初步指标（区间收益/规模/现任经理）→ 勾选入研究池并自动打领域标签。依赖基金分类/排行接口的可得性（技术选型验证项，降级方案：ZCode 维护「领域 → 基金」映射表作为周更截面数据）。ZCode 研究会话筛出的基金也可直接落库入池。
- **结构**：双层。数据层（自动维护，人不碰）+ 结论层（每基金一个手写 markdown：一句话定位、买入理由、关注点、退出路标）。
- **数据层字段（第一版约 20 个）**：静态档案（类型/经理/规模/成立/费率三档）+ 区间收益（近1月/3月/6月/YTD/1年）+ 风险（最大回撤/年化波动率/夏普）+ 前十大持仓及权重、股票仓位、业绩比较基准。

### FR2 组合综合评估（勾选任意子集触发）
- ①并排指标对比表（每基金一行，指标分组，风险列标色）；
- ②组合级：净值曲线、最大回撤、相关性矩阵热力图，叠加基准（沪深300/中证1000/自选）超额；
- ③重叠度穿透：同名重仓股合并、组合级个股合计权重、穿透后有效持仓数。
- **权重**：默认等权，界面可手调各基金占比（组合级指标随之重算）。
- **评分哲学**：不合成总分。异常值自动标色（回撤>30% 红、单股组合权重>10% 红、相关性>0.8 黄），风险提示文字随图展示。**工具摆事实，人做结论**（与 ROADMAP 决策辅助原则一致）。

### FR3 重仓股量化评估（穿透层）
- **指标集（第一版约 10 个/股）**：组合级合计权重（核心排序键）、PE/PB 当前值 + 近 5 年分位、近3月/6月/YTD 涨跌幅、52 周高低位置、年化波动率、最大回撤、总市值、所属行业。
- **口径诚实（强制，非选项）**：
  - 穿透基于最新披露报告期，界面显眼标注「报告期 YYYY-MM-DD，滞后约 70 天」；
  - 前十大之外的未披露持仓汇总为「未披露部分」条目，防止穿透精度被高估；
  - 财务指标（营收/净利同比、ROE 等）与新闻信号层留待二期/阶段 3，不在 v1。

### FR4 可视化与页面结构
- 仪表盘首页：持仓总览（收益/风险一眼看）+ 下挂四子页：
  - 画像库页（卡片墙 → 单基金详情，按领域标签筛选）
  - 领域探索页（选领域 → 浏览基金列表与初步指标 → 入研究池）
  - 组合评估页（勾选 → 三件套+基准）
  - 穿透分析页（勾选 → 重仓股合并表）
- 形态：本地 Web 应用（浏览器访问，纯本地运行，数据不出机器）。

## 4. 非功能需求

| 项 | 标准 |
|---|---|
| 数据新鲜度 | 行情/净值/估值分位：打开工具即时拉当日；画像截面（档案/持仓/指标）：每周刷新一次（随 investment-weekly 周一批次） |
| 数据正确性 | 指标口径写入文档；见验收标准② |
| 数据通路（约束） | 混合双路：时序数据免费接口直连（倾向 akshare，待选型验证）；持仓/财务截面由 ZCode 拉取落盘 CSV（复用 investment-weekly 模式）；领域基金列表/分类数据源待选型验证（接口优先，降级为 ZCode 领域映射表周更） |
| 成本 | 数据层 ¥0；不引入付费数据源 |
| 安全 | 本地运行；.env 与密钥不入库 |

## 5. 明确的非目标（v1 不做）

1. 自动申赎 / 下单 / 任何交易动作（永久非目标，同 ROADMAP）
2. 黑盒综合评分、收益预测
3. 全市场基金库覆盖
4. 实时持仓（持仓披露天花板即季频）
5. 基本面财务指标、新闻信号层（二期 / 阶段 3）
6. 多用户、云端部署

## 6. 验收标准（v1 完成的定义）

1. **场景跑通**：完整重做 2026-10-13 的诊断——录入 5 持仓 + 7 候选入研究池，选中 5 持仓，看到三件套 + 基准超额，穿透表中新易盛/中际旭创按组合权重排前列且超标标色；在领域探索页选「医药」能看到该领域基金列表，并把其中 1 只（如 000960）加入研究池。
2. **数值抽验**：随机抽 3 只基金的区间收益率/最大回撤，与 Wind 口径比对，偏差 ≤ 0.5 个百分点。

## 7. 移交技术选型阶段的开放问题

1. akshare 字段可得性实测：基金净值/档案、个股 PE-PB 历史序列（算 5 年分位）、前十大持仓兜底、**主题领域级基金列表/分类**（注意：排行接口按投资类型分类 ≠ 医药/黄金/红利这类主题领域，若接口给不了，降级方案为 ZCode 维护领域映射表）——**这是技术阶段第一道闸，若免费接口拿不到，数据通路约束需回滚重议**；
2. Web 框架确认（Streamlit 当前倾向 vs Dash/Gradio）；
3. 存储格式（CSV/Parquet + markdown 结论层 vs SQLite）；
4. 截面周更的自动化机制（ZCode 会话内跑批 vs 本地脚本）；
5. 与 investment-weekly 数据目录的共享与边界。
