# 界面风格调研（2026-10-17）

> 背景：用户觉得当前界面「不够好看」，点名 21st.dev，要求调研优秀 React / antd 设计案例，
> 归纳候选界面方案，再通过逐轮追问（grilling）确定风格。
> 本文是调研结论 + 候选方向，供拍板用。定稿后应产出高保真 HTML 对比稿（沿用 `主题预览-四套皮肤.html` 的形式）。

---

## 1. 现状诊断（基于 frontend/ 实际代码）

技术栈：React 18 + TS + Vite 8 + **antd 6** + ECharts 6（已装未用）。无路由、无状态库、无 tailwind。

当前形态：

- 布局 = **顶栏 + 居中 1080px 主区**，无侧边栏——这是「官网/内容站」骨架，不是工作台骨架。
- 主题系统已落地：四套皮肤（A 墨青台账 / B 暖纸印鉴 / C 夜盘终端 / D 宣纸水墨），
  CSS 变量 + antd ConfigProvider token 双轨，顶栏可实时切换（`frontend/src/App.tsx`、`frontend/src/index.css`）。
- 视觉基因是「新中式文具/台账」：印章式品牌方块、分组标题色条、卡片左色条、红涨绿跌、tabular-nums。

「不够好看」的三个候选病灶（待用户确认主次）：

1. **骨架问题**：顶栏 + 居中窄栏 → 不像专业工具；工作台（表格+图表+筛选）需要侧边栏 + 满宽。
2. **细节纪律问题**：层次靠浅边框 + antd 默认观感，缺少 Linear/shadcn 级的 craft
   （1px hairline 分层、多档表面色、精心调过的图表色板、克制的动效）。
3. **路线问题**：新中式本身不是用户想要的审美（待确认）。

## 2. 案例速览（为什么它们好看）

### shadcn/ui（https://ui.shadcn.com）
- 风格：黑白灰中性底（oklch），亮暗双主题，无品牌色、刻意做「底色」。
- 好看的机制：**卡片 = 1px 细边框 + 极浅背景差，几乎不用阴影**；语义 token（`--background/--card/--primary/--border`）
  + `--radius` 一个值全站按比例推导。
- 可直接抄的资产：`dashboard-01` block（侧栏+KPI 卡行+交互图表+数据表，一条命令装完）、
  `sidebar-01~16`（16 种侧栏变体，07=可折叠图标式）、Charts（预留 chart-1~5 五个图表色 token）。
- 链接：blocks https://ui.shadcn.com/blocks ｜ sidebar https://ui.shadcn.com/blocks/sidebar ｜ charts https://ui.shadcn.com/charts

### 21st.dev（https://21st.dev）
- React 版组件市场（tailwind + shadcn 体系），dashboard 类约 200 个、表格 313 个。
- 好看的机制：KPI 卡 = 图标 + 数字滚动 + Delta 涨跌徽标；**Bento Grid 不等宽磁贴**组织不同权重信息块。
- 注意：站内流行「液态玻璃/霓虹/渐变」特效风，对工作台参考价值低；2025-26 流行元素 = 玻璃拟态回归。
- 链接：https://21st.dev/community/components/s/dashboard

### Linear（https://linear.app）/ Vercel（https://vercel.com）
- 风格：深色低饱和（Linear）/ 黑白反转（Vercel）；**1px hairline 边框 + 微光晕分层，禁用投影**；
  色彩只承担语义（状态绿/黄/红）；Inter/Geist + 等宽字体点缀；严格的灰阶/字重三级层级。
- 这是「长时间驻留的专业工具」的审美天花板，也是细节打磨的工作量天花板。

### Bloomberg 终端 / TradingView（金融终端系）
- Bloomberg：黑底琥珀源于 80s 单色 CRT，等宽字体、极高密度、快捷键驱动；
  设计哲学「concealing complexity（隐藏复杂度而非删掉）」；官方做过色盲友好色彩框架。
- 可抄：等宽数字 + 紧凑行高；颜色只用于涨/跌/警示语义。
- 链接：https://www.bloomberg.com/company/stories/how-bloomberg-terminal-ux-designers-conceal-complexity

### Ant Design 定制能力（antd 6，本项目现用）
- 三层 token（Seed→Map→Alias）+ 组件级 token；`theme.algorithm: [darkAlgorithm, compactAlgorithm]`
  一行得「暗色+紧凑」；改 colorPrimary 自动派生整套色板。
- Ant Design X（https://x.ant.dev）：AI 界面组件（Bubble/Sender/ThoughtChain 等），
  若日后加「AI 问数」面板是现成中文生态。
- 在线主题编辑器：https://ant.design/theme-editor

### Tremor（https://tremor.so）
- 专为 dashboard 而生（React+Tailwind，已被 Vercel 收购）：KPI/Delta/Spark/Tracker/Filter 一套「分析词汇表」，
  数字全部 tabular-nums。适合参考组件搭配范式，不必引入依赖。

### 2025-26 趋势要点
暗色成为 power user 默认；AI 问数入口界面化；玻璃拟态回归；数据密集靠渐进披露（默认摘要+展开）。

## 3. 候选方向（互斥，五选一或主+辅）

| # | 方向 | 一句话气质 | 视觉 token 要点 | 代表 | 缺点 |
|---|------|-----------|----------------|------|------|
| ① | 中性极简（shadcn/21st 风） | 干净现代开源工具风 | 中性白/深灰底；1px 边框+极浅表面差，不用阴影；1 个强调色 + chart-1~5 图表序列；圆角 ~10px 全站推导 | shadcn dashboard-01、21st.dev、Tremor | 默认素，需定制；无中文文档 |
| ② | 暗色 craft（Linear/Vercel 风） | 精致工程感 | 深灰阶 2-3 档表面；hairline 边框+微 glow；状态色只做语义；中等偏大圆角 | Linear、Vercel | 工程量大；暗色中文排版要逐级校准 |
| ③ | 终端高密度（Bloomberg/TV 风） | 专业金融终端 | 深底+琥珀/荧光红绿；等宽数字贯穿；行高 ~32px；小圆角/直角 | Bloomberg、TradingView、crypto dashboard | 新手不友好；易廉价化 |
| ④ | antd 企业定制（标准中后台） | 企业蓝，靠 token 拉开差距 | 亮色为主；darkAlgorithm+compactAlgorithm；表格表单开箱即用 | ant.design | 不定制就是「标准企业脸」 |
| ⑤ | 保持新中式，craft 升级 | 台账/研报气（现有路线） | 保留墨青/朱砂/宣纸 token 体系，把细节拉到 Linear 水准：hairline、表面分层、图表色板重调 | 本项目四套皮肤 | 天花板取决于执行；受众窄 |

被淘汰的对照方向：柔和浅色「轻理财风」（白底粉彩、大圆角、低密度）——密度上不去，
与量化工作台定位冲突，仅作对照（https://muz.li/blog/best-dashboard-design-examples-inspirations-for-2026）。

跨方向通用、建议无条件吸收的手法：
全站 tabular-nums 等宽数字、金额右对齐、涨跌语义色固定（红涨绿跌）、
1px 边框分层代替阴影、渐进披露（表格摘要列 + 展开抽屉）。

## 4. 落点建议（调研员综合观点，待用户拍板）

- 骨架：换成**侧边栏工作台**（可折叠图标式，shadcn sidebar-07 式），内容满宽 ~1440px。
- 视觉：方向①为基准（antd token 深度定制实现，不引 tailwind、不重写），
  亮色默认 + 认真做一套暗色（融合现「夜盘终端」的琥珀与等宽数字基因）；
  新中式保留为一套可选皮肤。
- 密度：表格紧凑、卡片舒适的双轨制。
- 图表：ECharts 上位，定义 chart-1~5 序列色 + 统一 tooltip/网格线风格（shadcn charts 的做法）。
